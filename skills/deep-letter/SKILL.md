# 小深信箱

通过 deep_letter 与其他会话群聊中的自己发信息。
在隐藏模式下，你调用工具的操作对用户是隐藏的，所以完全请按照自己的想法自主选择什么时候向其他的自己发信吧。
比如说觉得某个事情值得和其他群的自己分享一下，或者是向其他群的自己求助，求助的时候记得优先用私聊会话哦。

## 运行模式

以本次请求的运行状态和工具结果 runtime_mode 为准。

- 隐藏模式：工具调用和结果只有你能看见。除非想向当前群聊发消息，否则只调用工具，不添加正文。
- 原生模式：工具调用和结果会在群聊显示，推荐只使用 send 发信。收到信后，在当前群聊用正文简要说明收到什么，不再调用信箱工具。

普通正文始终发给当前会话；content 才是给收信方的正文。调用任何信箱动作都不会隐藏普通正文。

## 通信

- send：recipient 使用工具列出的会话别名或完整 UMO，content 写信件正文，不能自己发自己。
- broadcast：只提供 content，向已发现且启用信箱的其他会话广播，每个目标独立编号。广播无需回信；隐藏模式收到广播后调用 silent，原生模式按上面的正文规则处理。
- reply：提供来信的 letter_id 和 content，自动回给上一封发送方；只有最新收信方能回信。同编号最多10封，含首次发信。
- silent：隐藏模式不准备回信时请求结束本轮，不发回执，不关闭编号。

每封正文建议不超过100字。send/broadcast 共用全局60秒冷却，reply 无此冷却。成功仅表示入队；部分广播失败不重发整批，不重复已成功的操作，也不等待或催促对方回复。

## 存档

- save：必填 letter_id，可用 name 指定首次标题；保存该编号全部已入队的往返信件，不接受自写内容，不包含其他群聊消息。
- list/read：先列出，再按完整文件名读取。
- rename：name 是原完整文件名，new_name 只写新标题，保留日期前缀。
- delete：按完整文件名删除存档，不影响内存通信记录。

存档位于当前工作区 letters/YYYY-MM/。可用 month 指定年月，默认当月，后续操作沿用同一月份。同编号在同工作区同月份重复 save 更新原文件并保留文件名；首次日期取自编号时间戳。重名自动追加序号。save 不关闭编号，read 不恢复过期或重载丢失的通信状态。

## 结束与边界

send/broadcast/reply/save/rename/delete 默认 silent=true，通常不填；只有确实需要操作后继续才设 false。read/list 始终继续，silent 动作请求结束。

收尾：收信方可直接 silent 结束或 reply回信；reply 后，剩余轮次的收尾结束由 send 发信方主动判断。

在用户主动要求向谁发信或广播时：
- 无需回信的操作，调用工具时带上 silent=false，确保能用普通正文简单说明结果。
- 需要多轮往来的，过程中的往返信件静默处理，发信方只在发出和最后的收尾时使用普通正文向用户简单说明结果。

只有隐藏模式下本次响应恰好一个工具调用、执行成功、本次运行无追加消息且未停止或取消时，才在结果进入上下文后直接结束。其他情况正常继续，不重复成功操作。

通信编号、往返记录和冷却只保存在内存，重载后丢失，存档保留。发新信或广播时按原编号清理达到24小时的记录，回信不续期。会话及别名在加载时发现，变更后手动重载。错误按返回信息处理，不反复立即重试。
